# 快速开始

本文档将帮助你在 5 分钟内快速部署 NexusAuth 统一身份认证平台。

## 前置要求

在开始之前，请确保你已具备以下环境：

- .NET 10.0 SDK
- Node.js 20+
- PostgreSQL 16+

## 快速部署步骤

### 步骤 1：克隆项目

```bash
git clone https://github.com/your-repo/NexusAuth.git
cd NexusAuth
```

### 步骤 2：启动 PostgreSQL（Docker）

```bash
docker run -d \
  --name nexusauth-db \
  -e POSTGRES_PASSWORD=your-password \
  -e POSTGRES_USER=nexusauth \
  -e POSTGRES_DB=nexusauth \
  -p 5432:5432 \
  postgres:16
```

### 步骤 3：配置数据库连接

修改 `src/NexusAuth.Host/appsettings.json`：

```json
{
  "ConnectionStrings": {
    "Default": "Host=localhost;Port=5432;Database=nexusauth;Username=nexusauth;Password=your-password"
  }
}
```

### 步骤 4：初始化数据库结构

```bash
psql -U nexusauth -d nexusauth -v ON_ERROR_STOP=1 -f production-init.sql
```

新库使用 `production-init.sql`。已有数据库则按 `database/` 中尚未执行的版本脚本升级，不执行最终初始化脚本。

### 步骤 5：启动认证服务

首次启动前通过配置或环境变量提供初始管理员。两个必要字段必须同时配置；用户已存在时，启动程序不会重置其密码：

```bash
export BootstrapAdmin__Username=admin
export BootstrapAdmin__Password='REPLACE_WITH_A_STRONG_PASSWORD'
export BootstrapAdmin__Nickname='System Admin'
export BootstrapAdmin__Email='admin@example.com'
```

```bash
dotnet run
```

服务启动后访问 http://localhost:5100

### 步骤 6：配置 Workbench OAuth 客户端

执行 Workbench seed.sql 添加管理后台所需的 OAuth 客户端：

```bash
psql -U nexusauth -d nexusauth -f admin/src/NexusAuth.Workbench.Api/seed.sql
```

该脚本只登记 Workbench 所需的 scope、客户端和客户端凭据，不创建登录用户。`demo/seed.sql` 仅用于需要演示数据的本地环境，不应作为生产初始化步骤。

### 步骤 7：启动 Workbench API

```bash
dotnet run --project admin/src/NexusAuth.Workbench.Api
```

### 步骤 8：启动 Dashboard

```bash
cd admin/src/NexusAuth.Workbench.Dashboard
npm install
npm run dev
```

访问 http://localhost:5273 使用统一账号登录。
