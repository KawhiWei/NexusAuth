# 数据库配置

本文档详细介绍 NexusAuth 数据库的配置过程。

## 使用 Docker 运行 PostgreSQL

### 启动数据库

```bash
docker run -d \
  --name nexusauth-db \
  -e POSTGRES_PASSWORD=your-secure-password \
  -e POSTGRES_USER=nexusauth \
  -e POSTGRES_DB=nexusauth \
  -p 5432:5432 \
  postgres:16
```

### 验证数据库

```bash
docker exec -it nexusauth-db psql -U nexusauth -d nexusauth -c "SELECT version();"
```

## 使用现有 PostgreSQL

### 创建数据库

```sql
CREATE USER nexusauth WITH PASSWORD 'your-secure-password';
CREATE DATABASE nexusauth OWNER nexusauth;
GRANT ALL PRIVILEGES ON DATABASE nexusauth TO nexusauth;
```

## 配置连接字符串

### NexusAuth.Host

编辑 `src/NexusAuth.Host/appsettings.json`：

```json
{
  "ConnectionStrings": {
    "Default": "Host=localhost;Port=5432;Database=nexusauth;Username=nexusauth;Password=your-secure-password"
  }
}
```

## 初始化数据库

Docker Compose 的首次数据库初始化执行 `production-init.sql` 创建结构，并执行 `admin/src/NexusAuth.Workbench.Api/seed.sql` 登记默认 Workbench 客户端。登录用户不由 SQL 创建，而是在 SSO 启动时从 `BootstrapAdmin` 配置创建。

```text
NEXUSAUTH_BOOTSTRAP_ADMIN_USERNAME
NEXUSAUTH_BOOTSTRAP_ADMIN_PASSWORD
NEXUSAUTH_BOOTSTRAP_ADMIN_NICKNAME
NEXUSAUTH_BOOTSTRAP_ADMIN_EMAIL
```

初始化是幂等的：用户名已存在时保留数据库中的密码。`demo/seed.sql` 不会自动执行，需要演示数据时由开发人员手动运行。

### 全新生产库

先由数据库平台创建空的 `nexusauth` 数据库，再执行最终 schema：

```bash
psql -U nexusauth -d nexusauth -v ON_ERROR_STOP=1 -f production-init.sql
psql -U nexusauth -d nexusauth -v ON_ERROR_STOP=1 -f admin/src/NexusAuth.Workbench.Api/seed.sql
```

`production-init.sql` 不删除数据库，也不包含 `ALTER TABLE` 或 demo 数据。SSO 启动后由 `NEXUSAUTH_BOOTSTRAP_ADMIN_*` 环境变量幂等创建系统管理员。

### 历史库升级

数据库通过 `production-init.sql` 从空数据卷初始化。当前不提供历史库的增量升级脚本；升级前应备份数据，并在新的数据库实例中完成初始化和数据导入。

### 验证表结构

```sql

```

## 数据库表说明

### 核心表

| 表名 | 说明 |
|------|------|
| users | 用户表 |
| oauth_clients | OAuth 客户端 |
| oauth_client_secrets | OAuth 客户端凭据 |
| api_resources | API 资源（Scope） |
| authorization_codes | 授权码 |
| refresh_tokens | 刷新令牌 |

字段、约束和索引的唯一权威来源是 [production-init.sql](../production-init.sql)，避免文档片段与实际 schema 漂移。

## 常见问题

### 端口被占用

```bash
# 查看端口占用
lsof -i :5432

# 或使用 netstat
netstat -an | grep 5432
```

### 连接失败

检查 `pg_hba.conf` 是否允许连接：

```bash
# 在容器内检查
docker exec -it nexusauth-db cat /etc/postgresql/16/main/pg_hba.conf
```
